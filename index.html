Tips:
  • Kabel: seret dari pin satu komponen ke pin komponen lain.
  • Menekuk kabel: klik kabelnya, lalu seret titik di tengah garis. Seret ujung kabel untuk memindahkannya ke pin lain.
  • Nama pin: tekan sebuah pin untuk melihat namanya (misalnya + / − , Anoda / Katoda, atau Basis / Kolektor / Emitor).
  • Menghapus: pilih komponen atau kabel, lalu tekan Delete.
  • Osiloskop: pilih komponen untuk melihat tegangannya. Tekan Autoset agar skala menyesuaikan sinyal.
  • Transistor dan MOSFET: pin 1 = Basis / Gate, pin 2 = Kolektor / Drain, pin 3 = Emitor / Source. Coba contoh “Transistor NPN sebagai saklar” dan “MOSFET N sebagai saklar”.
  • Panas dan ledakan: pilih komponen untuk melihat suhunya. Korsleting, LED tanpa resistor, atau kapasitor terbalik membuatnya panas lalu meledak. Perbaiki rangkaian, lalu tekan Reset Simulasi.
