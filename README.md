# GetSimulated

Simulator elektronik sederhana berbasis web (satu file `index.html`, tanpa dependensi).

## Pakai
Buka `index.html` di browser. Letakkan komponen, sambungkan dengan Kabel, **wajib pasang GND**, lalu pilih komponen untuk mengubah nilainya.

## Teknis
MNA + transien backward Euler, Newton-Raphson untuk LED. Lihat `LOG.md` untuk riwayat dan keterbatasan.

## Aturan repo
Setiap review atau perubahan **wajib** dicatat di bagian paling atas `LOG.md`.
